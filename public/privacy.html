Kebijakan Privasi — Many Money

Terakhir diperbarui: 24 November 2026

Many Money menghargai privasi pengguna. Dokumen ini menjelaskan bagaimana data Anda dikelola saat menggunakan aplikasi Many Money (web maupun Android).

1. Mode Guest (Penyimpanan Lokal)

Jika Anda menggunakan Mode Guest, seluruh catatan transaksi, aset, anggaran, memo, dan pengaturan disimpan hanya secara lokal di perangkat Anda (localStorage) dan tidak dikirim ke server pihak ketiga mana pun.

2. Akun Google & Sinkronisasi Cloud (Opsional)

Jika Anda memilih masuk menggunakan Akun Google atau email melalui Supabase Auth, alamat email dan ID pengguna Anda digunakan hanya untuk mengautentikasi akun serta menyinkronkan data keuangan Anda ke database Supabase secara terenkripsi (dilindungi Row Level Security per pengguna). Kami tidak menjual, menyewakan, atau membagikan data Anda kepada pengiklan.

3. Izin Kamera, Galeri & Mikrofon (Opsional)

  • Kamera & Galeri: Hanya digunakan saat Anda mengetuk fitur Scan Struk untuk membaca teks struk secara lokal di perangkat menggunakan OCR (Tesseract.js). Gambar struk tidak diunggah ke server kami.
  • Mikrofon: Hanya digunakan saat Anda mengetuk fitur Input Suara untuk mengubah ucapan menjadi teks transaksi melalui layanan pengenalan suara bawaan browser/OS.

4. Penghapusan Data & Akun

Anda dapat menghapus seluruh data transaksi kapan saja melalui menu Menu → Cadangan & Reset → Kosongkan Semua Transaksi. Untuk menghapus akun cloud beserta seluruh data yang tersinkron di Supabase, silakan kirim permintaan ke yaserarafatt03@gmail.com dengan subjek "Hapus Akun Many Money" dan sertakan alamat email akun Google Anda. Data akan dihapus permanen maksimal dalam 7 hari kerja.
